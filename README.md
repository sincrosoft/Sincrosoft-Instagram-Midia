# Sincrosoft — mídia do Instagram

Imagens públicas usadas pela API do Instagram para publicar os posts da Sincrosoft. A API busca cada imagem em:

`https://raw.githubusercontent.com/sincrosoft/Sincrosoft-Instagram-Midia/main/posts/<post>/<arquivo>.jpg`

Não edite aqui: as artes são geradas no kit de Instagram (repositório privado) e copiadas para cá com `node api/instagram.mjs midia`.
